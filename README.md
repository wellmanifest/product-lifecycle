# Wellmanifest Product Lifecycle

Experimental standard for versioned products and services: registration,
release, jurisdiction-aware availability, deprecation, withdrawal and sunset.

The normative artifacts live in `standard/`; architecture and lifecycle
guidance live in `docs/`. This repository never bills customers, stores
personal data or deploys workloads.

It composes with `wellmanifest/legal-lifecycle` for license and location
rules and can be referenced by `wellmanifest/saas-lifecycle` as the catalog
behind a commercial offer.
